# Pokédex em C

Projeto de uma Pokédex desenvolvida em linguagem C, com o objetivo de praticar conceitos fundamentais de programação, como estruturas de dados, funções, vetores, condicionais e manipulação de arquivos.

## Sobre o projeto

Esta aplicação simula uma Pokédex onde o usuário pode consultar informações de Pokémon através de um programa executado no terminal.

O projeto foi desenvolvido como prática de lógica de programação e desenvolvimento utilizando a linguagem C.

## Funcionalidades

- Busca de Pokémon
- Exibição de informações dos Pokémon cadastrados
- Leitura de dados através de arquivo `.txt`
- Execução pelo terminal

## Tecnologias utilizadas

- Linguagem C
- GCC (compilador)
- Git
- GitHub

## Estrutura do projeto

```text
Pokedex-em-C/
│
├── pokedex.c       Código principal do programa
├── pokemon.txt     Banco de dados dos Pokémon
└── README.md       Documentação do projeto
```

## Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/M0US3P4D777/Pokedex-em-C.git
```

### 2. Acesse a pasta do projeto

```bash
cd Pokedex-em-C
```

### 3. Compile o programa

```bash
gcc pokedex.c -o pokedex
```

### 4. Execute o programa

Windows:

```bash
.\pokedex.exe
```

Linux:

```bash
./pokedex
```
